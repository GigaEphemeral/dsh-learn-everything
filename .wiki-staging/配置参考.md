# 配置参考

两条配置通道：**插件配置页**（推荐，保存即生效）与**环境变量**（兜底/CI）。优先级：插件配置 → 环境变量 → 默认值（`index.js:61` `resolveObsidianConfig`）。

## 一、插件配置页

DSH → 插件 → dsh-learn-everything，字段定义在 `index.js:46-54`，面板表单在 `src/client/obsidian-config-form.js`：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `apiKey` | secret | 空 | Obsidian Local REST API 的 API key；只存服务端，响应中永不下发（`obsidian-config-form.js:3`） |
| `baseUrl` | string | 空 → `https://127.0.0.1:27124` | REST API HTTPS 地址 |
| `vaultName` | string | `learnEverything` | 目标 Vault 名 |
| `ingest` | boolean | `true` | 摄入后是否触发 karpathywiki 编译 |
| `grillPersona` | string | 内置严格教师人格（`src/persona.js:18`） | 追问教学人格 |

行为：

- **保存前自动测试连接**（`/obsidian/api/test-connection`），失败不写入；保存后再次校验（`src/client/ObsidianConfigCard.js:74-99`）
- 全部字段 `volatile()`：改完即生效，无需重启 DSH
- 未配置 key 时，接口返回 `503 obsidian-not-configured`（而非 404），路由仍注册以便面板提示（`index.js:75-79`、`src/sidebar/routes.js:8`）

## 三、复习调度参数

间隔策略（`src/learning/review.ts`）：答对后 `interval_days ×= 2`，下限 1 天、上限 30 天（`MIN/MAX_INTERVAL_DAYS`、`INTERVAL_GROWTH_FACTOR = 2`），答错重置为 1 天且 `correct_streak` 归零；`next_review = 当前间隔` 推算，到期项由选题权重优先命中。

## 四、密钥与状态

- `.env*`（除 `.env.example`）与 `.state/` 均在 `.gitignore` 中，不入库
- API key 不进入浏览器，面板数据一律经围栏路由（`src/sidebar/routes.js`）代理 Obsidian REST
