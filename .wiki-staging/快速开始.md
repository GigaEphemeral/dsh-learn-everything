## 三、配置连接

DSH → 插件 → dsh-learn-everything → 填写 `apiKey`（secret）+ `baseUrl` + `vaultName` + `grillPersona`（追问教学人格）：

![DSH 插件配置](https://github.com/GigaEphemeral/dsh-learn-everything/raw/master/detailDoc/screenshots/plugin/dsh-config.png)

- **保存前自动测试连接**，错 key 不保存；保存即生效（volatile 配置，无需重启）
- 优先级：插件配置 → 环境变量 → 默认值；未配置时接口返回 `503 obsidian-not-configured`
- 完整环境变量清单见 [[配置参考]]

## 常见问题

- **REST API 列不出空文件夹**：`Inbox/` 在磁盘存在但不出现在 `/vault/` 列表，属正常行为。
- **编译耗时长**：karpathywiki 编译约 6 分钟/源（LLM），CLI 会阻塞等待；超时/轮询/settle 均可配置（见 [[配置参考]]）。
- **限流**：编译遇 request burst 时，来源已安全入库，`compile-cli pending` 列出待编译项，冷却后补编译。
